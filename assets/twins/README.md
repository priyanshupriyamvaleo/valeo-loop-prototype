# Twin portraits

Drop portrait images here, named by twin id:

    huberman.jpg   attia.jpg   sinclair.jpg   ...

Requirements
- Portrait crop, subject's face in the upper third (the glass panel covers the
  bottom two-thirds of the card).
- Minimum 800 x 1200 px. JPG or WebP.
- Rights cleared for the person depicted before anything is published.

Until images land, the deck renders a monogram treatment on a tinted glass card,
which is a drop-in replacement — no layout change when the photos arrive.
